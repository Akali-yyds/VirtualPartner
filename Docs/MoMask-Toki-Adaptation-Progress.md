## 实际证据

三段真实指令：右手挥手 3 秒、左手指向 4 秒、双手摊开 5 秒。

| 事件 | 相对提交时间 |
|---|---:|
| LLM 首 token | 0.688 秒 |
| 首完整段 | 1.540 秒 |
| LLM 规划完成 | 1.770 秒 |
| 首个实际身体动作 | 约 2.413 秒 |
| 第三段播放结束 | 约 14.389 秒 |

这是单次暖运行证据，不是稳定延迟统计。第三段源动作出现“摊手变成举手”的语义偏差，样本保留，不能把执行成功记为动作意图通过。

证据目录：`F:/Project/MotionExperiments/Evidence/Playground/20261011-145349-467/jobs/20261011-145500-123-23213f/`。

该第三段的初版头部对照位于 `segments/002/review-20261011-151127/`。原适配头倾约 -31.09° 至 -19.41°；修正后约 -2.18° 至 +9.38°。近似碰撞体检测的最大穿插深度从 0.1224m 降至 0.0753m，**仍有明显残余问题，未通过避碰验收**。此记录早于后续肘部候选修正，需要以同一原始样本复测最新代码。

头部原因：源骨架颈到头的连线并非脸部朝向；训练数据均值本身包含约 42° 的前向分量。直接以该连线驱动目标颈头会引入姿态偏置。当前用源参考方向与目标基准方向分离处理，仍待点头、侧倾及转身等样本验证。

官方编辑接口已验证一个接缝样本：边界最大形状跳变由约 0.618m 降至 0.010m，但保留前缀仍有约 0.109m 的最大漂移，因此未默认启用。证据：`F:/Project/MotionExperiments/Evidence/TokiAdaptation/continuation-001/`。

## 保持规划回归

原失败样本：`F:/Project/MotionExperiments/Evidence/Playground/20261012-011407-857/jobs/20261012-011514-283-286999/`。LLM 将“抬到肩高并一直保持”错误拆成 9999 秒定时保持及第二段无限保持；不删除或替换该结果。

修正：规划明确以到位段的 infinite 表达无限保持，不为维持姿态再生成动作；有限保持必须引用实验指令中的时长依据。引用检查只能验证出处，不能证明自然语言语义正确。解析器按行依次交付，避免同一 token 批次内后续坏段导致前面完整有效段丢失。

真实复测已返回单段抬手、completion=infinite、holdSeconds=0，首完整段约 1.10 秒。此次仅验证真实规划，未等同于角色保持与接管通过。结果：`F:/Project/MotionExperiments/Evidence/TokiAdaptation/hold-planner-20261012/`。

自动检查：`python -m unittest discover -s Tools/MotionLab -p 'test_*.py'`，13 项通过，包含流式先生成、失败段保留、取消结果不可播放、保持契约及同批坏段隔离。这些检查不替代 Unity 视觉验收。

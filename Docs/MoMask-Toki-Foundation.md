## 第一阶段改动

- 固定源格式 `humanml263-v1`、坐标边界 `humanml-x-reflection-v1`。位置反射 X；根朝向先将官方 world→local 四元数求逆，再作基变换 `S R S`。根四元数以 Unity `xyzw` 输出。旧位置文件仍可加载，根朝向缺失时明确标为根据髋部推断。
- 官方 263 维：根速度／高度 `[0:4]`，相对位置 `[4:67]`，21 个 6D 通道 `[67:193]`，关节速度 `[193:259]`，左踝／左趾／右踝／右趾接触 `[259:263]`。6D 原值继续保存，**不是已转换为 Unity 骨骼局部旋转**。推理先使用训练 mean/std 反归一化，再调用官方恢复。
- 增加官方 RIC／FK 审计、每帧长度对照、位置 IK→FK 回环、SHA256 原始样本索引。官方代码版本 `94a6636c9c463b7a9414c3401a6f1b67e6c51824`。
- 基础播放独立控制根 yaw 与躯干骨段方向。关闭比例补偿、碰撞修正、脚锁和显式头部目标；不引入数据均值脸部基准。源骨段只能确定 swing，脸部／掌心及轴向 twist 没有观测真值；头骨保留绑定局部旋转，不声称准确恢复表情朝向。
- `TokiFoundationCalibration.json` 保存版本化映射、完整绑定层级及本地姿态、身体参考系、局部长度。世界坐标与轴明确标记为采样诊断，不重新当作绑定。加载时核对映射、绑定和身体参考系；原始模型骨架不变。
- 时间轴检查从同一干净实验状态逐帧重建，冻结 Idle 时间，按实际协调器写入后的角色测量。暂停后不会继续采样出漂移的 Idle。
- 默认按钮为“重播整场”，另有“重播当前段”；保留段顺序、显式保持／解除、失败或缺失原因，不调用 LLM 或 MoMask 重生成。新增打开保存演出目录入口。拖动时间轴进入单段检查，整场接续需重新重播；生成进行中不能用检查式 seek 改写现场状态。
- 新检查写到 `inspections/<UTC timestamp>-<layer>/`，包含配置和绑定快照，不覆盖旧播放报告。历史样本的原配置优先；使用最新配置需勾选明确选项。旧样本没有完整绑定快照时，只能用已记录的当前资源比较，不能宣称重现了不存在的历史标定。
- 源骨架以橙色左侧、蓝色右侧、白色中央链区分，并显示 L/R、根前向及源零高度参考线。多视角中仅挪动源骨架的展示位置，不修改动作数据。

## 问题归因与边界

| 问题 | 已得到的证据／处理 | 结论 |
|---|---|---|
| “拳击反了” | 用户点击的是 30 秒演出的最后一段 5 秒轻微律动；旧按钮仅重播最后一段。现在整场与单段分开 | 修复重播歧义，不能算拳击意图通过 |
| 头部后仰 | 异常源样本在官方 RIC、FK 中的颈→头方向都与中性样本不同；基础传递仍出现后仰 | 骨段方向不是可见脸部方向；没有证据支持整个动作翻转 180° |
| 旧头部补偿 | 同样本旧修正后的推断头倾仍约 42–49°；基础约 50–64° | 均值参考／限幅未解决该样本，不作为新基线 |
| RIC 与 FK 差异 | 17 段重导出位置全部与原 motion.json 相同；两组生成通道彼此存在偏差 | 旋转恢复继续作诊断，不替换默认骨链 |
| 腿部晚响应 | 保留以前的遮罩失败样本；现有 body scope 包含未被保持占用的下肢 | 旧专项已修复，回归继续核对 |
| 高度与姿态积累 | 分开绑定、Idle、演出；段落 Y 不叠加独立片段原点；整场连续重播复位测量为零 | 当前复位回归通过，浅蹲仍保留原相对高度变化 |
| 长演出缺段 | 保存原 20 秒失败样本与后来真实 30 秒样本 | 失败不删除；缺失段不伪装为完整演出 |

异常末段 RIC／FK 的逐关节位置差：中位 **0.02942 m**、最大 **0.17268 m**（FK 使用首帧骨长）。改为每帧 RIC 骨长后仍为 **0.02743 / 0.12308 m**，所以不能只归因于骨长变化。以同一 RIC 位置重新求官方 IK，再 FK，最大误差 **4.25e-7 m**；转换数学可以闭合，直接生成的两组冗余通道没有严格一致。

17 段中最大 RIC／FK 差异达到约 **0.984 m**，涉及其他源异常样本。该值是人形源骨架两种恢复的差异，不是 Toki 实际播放误差。现阶段不保证源动作符合自然语言意图，也不能从关键点确证脸部／手掌朝向。

## 检查结果

- Python：18 项通过，包含官方根恢复对照、反射回环、标准片段骨长／左右／前后／浅蹲，以及已有规划回归。
- Unity：8 个确定性片段，7 个运动中时刻加重复 seek 检查。最大方向误差 **0.02798°**，骨长变化 **0**，同帧重复最大位置差 **8.56e-8 m**、角度差 **0°**；复位相对同一 Idle 采样的位置／角度差均为 **0**。
- 整场真实保存样本：5 段共 30 秒，连续两次重播，跨度 **30.027 / 30.034 秒**，复位无残留。此测试没有重新生成动作，不是新的 LLM 响应延迟测试。
- Debug：冲突动作被拒绝，复位后 Debug 占用保留；只释放测试自身申请的固定。
- 进入姿态的 0.35 秒混合阶段故意偏离源目标，报告同时保留总误差与 `settledDirectionError`，避免将过渡误认为恒定映射错误，或从报告中隐藏过渡偏差。
- Unity 编译检查已完成；开发中一次 `SemanticBone` 枚举比较编译错误已修正。官方 NumPy 弃用警告单列，不修改模型环境掩盖警告。

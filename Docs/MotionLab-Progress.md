## 当前实施内容

独立 Unity 场景已比较：语义目标 → 现有 IK、MoMask 完整片段生成、DiP 短段接续。实验面板提供自然语言输入、路线选择、重播、中断、复位、源骨架与当前角色并排显示；保留全部主样本与早期失败结果。

角色副本继续经 `ActionCoordinator` 写入骨骼。实验场景不挂载 Momotalk、LlmRelay、历史或 Memory 组件；语义实验 worker 只读取既有本机配置，发送独立测试指令，不上传用户聊天。学习式模型没有接入日常对话。

本机环境：Windows / Unity 6000.3.12f1 / i7-9750H / 16 GB / GTX 1650 4 GB。MoMask 与 DiP 使用 F: 独立 Python 3.10 / PyTorch 环境，原有 GPT-SoVITS 环境未改动；现有 TTS 配置运行在 CPU。

## 已取得的结果与边界

| 项目 | 当前证据 | 不能据此宣称 |
|---|---|---|
| 语义路线 | 12 条指令 × 3 次真实 LLM 解析及播放初测；发现并补齐下垂／复位关系映射 | 全部动作自然、任意指令均可支持 |
| MoMask | 12 条指令 × 3 个种子均有真实生成；原始、BVH 拟合、脚部 IK 分别保留 | 站立约束、掌心朝向、动作顺序全部正确 |
| DiP | 4 个代表场景 × 5／10 步生成；数据前缀与当前角色转换前缀分别记录 | 已成为实时闭环角色控制器 |
| 独立环境检查 | 6 项基础检查、9 项保持／局部接管／Debug 优先级／中断检查通过 | 几何通过等同于语义与观感通过 |
| 重定向修复 | 修正未映射父节点受 Idle 驱动造成的 FK 差异；首个复测样本骨段方向误差约 0.03°，骨长变化 0 | 脚底支撑或完整关节限制已解决 |
| 语音并发 | 三条路线均取得真实生成+语音运行记录，另有无录屏各 2 条同步策略对照 | 冷启动已达到 2–3 秒，或小样本可以保证稳定延迟 |

阶段测量：语义解析 36 次中位数约 **1.26 秒**；MoMask 暖推理中位数约 **0.68 秒**，两次官方 100 迭代 BVH 转换合计中位数约 **6.12 秒**。这是分阶段计算数据；其中部分采样期间有其他实验负载，不能当成严格隔离的性能承诺。实际角色可直接回放原始位置输出，BVH 后处理单独比较，不混入模型推理时间。

无录屏真实并发动作先行样本：语义首动作 **1.78 秒**、MoMask **42.92 秒**、DiP **30.16 秒**。后两者包含每次重启 Python 和模型加载，不能用暖推理数值替代。三者首音频分别约 **19.35 / 23.13 / 35.37 秒**，欠载计数 0。首字节与播放启动接近；优先定位 TTS 服务返回首音频前的耗时，而不是直接缩短 Unity 缓冲。

已发现脚滑和动作意图偏差。有限长度生成片段不支持“无限保持直到停止”的完整交互语义；位置输出不能可靠确定手腕扭转。实验工具早期还出现过 NumPy 兼容、重复加载导致的显存／提交内存不足及前缀转换类型问题，失败记录保留，修复后单独复测。编辑器域重载打断的录制不计作完整通过。

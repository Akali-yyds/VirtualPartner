# Icon sources

Material Symbols Rounded: Google material-design-icons, variablefont/MaterialSymbolsRounded[FILL,GRAD,opsz,wght].ttf.
Source: https://github.com/google/material-design-icons/tree/master/variablefont
Downloaded 2026-10-02. Official Apache 2.0 license retained in MaterialSymbols-LICENSE.txt.

Individual white symbols are rasterized at 192 x 192 using the default variable-font instance. PhoneGlyph tints these textures. Recent uses view_carousel. Application icons are original colored compositions; Settings and Debug incorporate the settings and terminal symbols. No external app trademarks are used.

Theme and rounded sprites are prepared by PhonePolishAssets. PNG texture imports use uncompressed RGBA, bilinear filtering and no mipmaps for stable UI rendering.
